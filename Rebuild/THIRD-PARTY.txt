The optional tab-layout companion (parking/layout_api.py) is a separate
GPL-2.0-or-later program communicating with the application using JSON.
It uses the official iTerm2 Python API, version 2.7 (GPLv2), protobuf 3.20.3
(BSD-3-Clause), and websockets 10.4 (BSD-3-Clause).

Pinned package sources: https://pypi.org/project/iterm2/2.7/
https://pypi.org/project/protobuf/3.20.3/
https://pypi.org/project/websockets/10.4/

The build retains each distribution's license and metadata in the vendor
directory. The companion's complete source is included in the app bundle.
The companion only changes the order of an exact existing set of tabs using
iTerm's public API; ordinary parking and opening use macOS Automation.
